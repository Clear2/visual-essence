## [0.1.0] - 2026-08-06

### Added

- Douyin URL extraction for direct links, short links, copied share text, and
  Selected-page `modal_id` links.
- Safe metadata retrieval, guarded playback proxying, audio transcription, and
  transcript-grounded LLM interpretation.
- Conversation-based result pages with live public processing activity,
  persistent follow-up questions, and refresh-safe restoration.
- Responsive Next.js conversation workspace and FastAPI backend with automated
  frontend and backend tests.
- Bilingual English and Chinese documentation, contribution guidelines,
  security policy, MIT license, and GitHub Actions CI.
